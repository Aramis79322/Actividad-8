# Manual del Usuario — Juego de Naves v1.0.0

## Instalación
Windows con g++ y windows.h/conio.h.

## Controles
W arriba, S abajo, A izquierda, D derecha, ESPACIO disparar.

## Objetivo
Destruye asteroides (O) sin chocar. Cada destrucción +10 pts. 3 vidas.

## HUD
PILOTO, VIDAS, SCORE, NIVEL arriba a la izquierda.
